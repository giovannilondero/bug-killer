# Bug Killer

A top-down shooter where the enemies are the **open bugs in your backlog**. Every sprint is a project, every boss is that project's worst ticket, and every now and then a client pops into the chat with a "super urgent" mission.

**Play it at [bug-killer.giovannilondero.dev](https://bug-killer.giovannilondero.dev/)**, on desktop or on the phone.

![Sprint 4: the FND-2245 boss fills the arena with undefined while Ugo asks for no hits during a live demo](docs/gameplay.webp)

```sh
pnpm install
pnpm dev        # http://127.0.0.1:5199
pnpm check      # typecheck + oxlint (Ritmo rules) + ritmo-devtools lint + headless tests
pnpm build && pnpm serve   # production on Node: game + run server on a single port (PORT, default 8080)
pnpm serve:cloudflare      # production as deployed, locally: the Worker and its Durable Object (http://localhost:8787)
```

`?tutti` in the URL unlocks every sprint for the session.

## How to play

| Control | Action |
|---|---|
| WASD / arrows | move |
| Mouse (hold) | aim and shoot |
| Space / Shift | dash (briefly invulnerable) |
| Q / E / right button | `git reset --hard`: clears the screen |
| F / middle button | drop a Breakpoint where you stand |
| P / Esc | pause |
| M | audio on/off |

Hover the crosshair over a bug to read its ticket.

- **Priority → enemy type.** Lowest/Low are weak, High are fast, Highest are tanks that spawn 3 regressions when they die.
- **Type → what it leaves behind.** Most tickets are Bugs. From Side Quests on (and in Endless after the first waves) some are **Stories**, bigger and ringed in green with a bookmark: closing one splits it into 2 smaller, faster **sub-tasks** (`KEY-123-1`, `KEY-123-2`, blue boxes on their back). From sprint 5 (and in Endless once it gets that far) some are **Epics**: a big ticket ringed in purple, sitting in a nest out in the open. It never moves, but about every 3 s it releases a Lowest or Low sub-task (`KEY-123-1`, `KEY-123-2`, …), up to 6 alive at once, until you close it. Its status changes nothing: an Epic never deploys, wanders or reopens. A Highest Story or Epic still leaves the 3 regressions every Highest does. The wave can't end while an Epic is open. The tooltip shows the type.
- **Status → behaviour.** *Blocked/On hold* are shielded (half damage), *Ready for QA/UAT/review* may reopen (`REOPENED`), *In development* move erratically. From Foundry on, *Deploying* bugs (🚀) stop next to a developer, flash for about a second and explode: everyone in the blast loses 1 sanity and nearby bugs take damage, so one can set off the next. Shoot them from afar and they go off harmlessly where they are. Clearing one with `git reset --hard` still sets off its blast, so it hurts any developer in the radius; the blast never hurts bosses.
- **Sprints.** Glacier → Side Quests (seven small projects) → Keystone → Foundry → Monorepo (one repo for everything, with Epics and `git push --force`) → Microservices (forty services, and 🤬 Flame war) → Legacy (a green-phosphor 80s terminal, COBOL included: everything is unlocked, and the tickets are tougher) → Production (the finale: it is live, it is Friday, and it is the hardest sprint of all, with the toughest tickets), each unlocked by clearing the one before. Projects, keys and tickets are made up (`src/content/backlog.ts`).
- **Bosses.** `GLC-37` the dispenser that only stops on a timeout, `QUIZ-276` the crash that restarts somewhere else, `KEY-3242` the 2FA that wants a second factor, `FND-2245` `TypeError: Cannot read properties of undefined`, `MONO-4096` the merge conflict: at half health it splits into *ours* and *theirs*, two halves that move and fire in mirror across the arena, and the sprint is only done when both are fixed (the one left alone fires faster), `MSVC-1024` the race condition: it forks into two twin threads, *main* and *worker*, that chase each other round the arena. Fix one and the other starts restarting it: a dashed ghost marks where it comes back and counts down about 4 seconds. Fix the other before it hits zero and the race is closed; too slow, and the first twin is back at full health. `LGC-1983` the infinite loop (`10 GOTO 10`): it runs a faint ∞ circuit round the arena, faster every lap (the lap is under it), leaving a trail of slow hostile shots behind it and a ring of them each time it starts a new lap. Stay off the circuit and shoot it as it goes by. `PROD-404` the stack overflow (`RangeError: Maximum call stack size exceeded`): a tower of 6 stack frames. Every sixth of its health you take off, the top frame drops off (5 of them in all: the 6th, at the bottom, is the tower itself) as a bug that runs for the developers, faster the shorter the tower gets; while any dropped frame is alive the tower is shielded, as the 2FA is, and your shots bounce off. Close the frames, then go back to the tower. Each sprint's card in the menu names its boss and says in a line how it fights.
- **Clients** (made up): Ugo WRITES EVERYTHING IN CAPS!!!, Ornella is "following up on my previous email", Kevin sends you voice notes, Samanta asks "while you're at it", Gualtiero says "it worked on staging", Fabrizio (from Monorepo on) only ever answers "+1" or "up": what he wants is on the pinned mission card, Debora from marketing (from Microservices on) agrees with everything as long as it is "more pop" by Friday. A mission completed earns story points and a power-up. A mission failed means scope creep: new `ESC-*` bugs in the arena.
- **Resurrected bugs.** Every now and then a client swears a bug you closed "is not fixed yet": it comes back to the arena as a zombie 🧟 (tougher, and missing from the release notes until you close it again) while the client laughs in the chat and tells you to work harder.
- **Tobia** (Tech Lead) shows up when you're slow (too long without closing a bug, or bugs piling up) and asks "are you using the _tools_??", then leaves them next to you: 🤖 Tools, homing shots.
- **Power-ups:** 🔥 Hotfix, 🔀 Refactor, ☕ Coffee, 🛡️ Green tests, ⏪ git reset, 🍕 Pizza, 🤖 Tools (from Tobia only), 🧠 AI, ❄️ Code freeze (from Keystone on: while it lasts every hit freezes the bug for about 2 s, whatever the weapon; bosses are only slowed by half), 🧪 Memory leak (from Foundry on: while it lasts every hit poisons, whatever the weapon: the bug keeps losing health for about 6 s, faster with every hit piled up, bosses included; when a poisoned bug dies the leak passes to the nearest bug).
- **Statuses.** Bugs and bosses can carry status effects, developers never do. A frozen bug turns to ice and stops, a poisoned one oozes green, a burning one (🔥 *This is fine*) loses health fast for about 3 s and sets on fire every bug it touches; whatever a status does later counts for the developer who applied it.
- **Breakpoints** (from Keystone on): every sprint starts with 🔴 2 Breakpoints, counted next to `git reset` in the top-left corner, and rare drops (about as rare as ⏪) add one, up to 5. Drop one where you stand: when a bug or a boss comes near it, it goes off, damaging everything around it and freezing the survivors. It never hurts developers; in multiplayer each developer has their own, and the points of a trap go to whoever set it.
- **Weapons:** some pickups are a weapon you hold for a while instead of the basic gun; its timer is in the top-left corner, a new weapon replaces the one in hand, and when time runs out the basic gun is back. 👥 Pair programming (from Side Quests on) fires two parallel shots. Hotfix speeds up any weapon; Refactor and Tools also upgrade Pair programming, so Pair programming + Refactor fires six shots. 🚀 `git push --force` (from Sprint 5 on, rare) fires a slow rocket now and then: it explodes on the first bug or boss it touches, or where the crosshair was when you fired (a dashed ring marks the spot), hurting every bug within reach of the blast but never a developer. Hotfix makes it fire faster; Refactor and Tools don't change it. 🤬 Flame war (from sprint 6 on, and late in Endless) sprays a short cone of fire instead of shots: little damage, but to every bug inside it, and it sets them on fire. Hotfix makes it puff faster; Refactor and Tools don't change it.
- At the end of a sprint: release notes with the closed tickets (Stories and Epics marked as such, sub-tasks only counted: "+ 14 sub-tasks"), copyable as Markdown.
- **Endless:** the ∞ card below the sprints. Every open bug from every project, picked at random, forever; every 6 waves the next sprint's boss arrives, in campaign order, then round again (every client writes in too), and every boss beaten makes the next round harder (tougher, faster bugs, bigger waves closer together). It only ends when you burn out; your record stays in the menu. Under its card you pick the arena: **Normal**, **Small** once Hotdesk is unlocked, or **Walls** once Cubicles is (each arena opens with the bonus level played in it). Every arena keeps its own record, and so does hardcore in each of them; in multiplayer the host picks the arena in the lobby for the whole team, and teammates see the pick as it changes.
- **Hardcore:** the ☠ toggle above the sprints, available from the start, applies to every run until you turn it off. Max sanity is 1, so one hit ends a solo run; 🍕 Pizza never drops (not from bugs, missions or calls), 🛡️ Green tests still do; reviving a teammate brings them back with 1 sanity. In multiplayer the host sets it in the lobby for the whole team, and teammates see it as soon as it changes. Every sprint (and bonus level) you clear in hardcore gets a ☠ badge on its card, and Endless keeps a separate hardcore record in each arena. It unlocks nothing extra; the HUD and the end-of-run screen say when a run is hardcore.
- **Walls:** some arenas have walls. Nobody walks through them, developers or bugs (bugs find their way round to you), and they stop every shot, yours and theirs; a rocket goes off against them, and neither Flame war nor an explosion reaches what is behind one. Hide behind a wall, but so can they.
- **Bonus levels:** the ★ cards under the other modes, optional and outside the campaign: clearing one unlocks nothing, but it keeps its own best score. Each draws a fixed set of tickets at random from every project, never the same one twice (playing them with what the sprint that unlocks it has: before that, a Story or an Epic is a plain bug), then calls one of the campaign's bosses. **Hotdesk** (unlocked by closing sprint 3) is a small arena, 30 tickets and the 2FA boss `KEY-3242`. **Cubicles** (unlocked by closing sprint 5) is an open space cut up by walls, 30 tickets and the crash boss `QUIZ-276`. In multiplayer the host can pick any bonus level they have unlocked.
- **Bonus calls:** every now and then a client calls you. On Meet a room appears in the arena: stay inside it for 5 seconds. On Slack their messages float around the arena: go read them all. Answering earns story points and a power-up; ignoring costs nothing but a passive-aggressive message. An arrow points the way when it's off screen.
- **Minimap:** the whole arena in a box, top right below the story points (bottom centre on phones, between the thumbs): bugs in their priority colour, bosses, power-ups, the call to answer, the mission's blocker ticket blinking, and a rectangle for what you can see.
- **AI:** the rarest drop. Once picked up, it places a turret on the spot that shoots the nearest bug on its own for 12 seconds (the points go to whoever picked it up). Every now and then it hallucinates and shoots at nothing.
- **Play together:** up to 4 developers on the same backlog. In the menu you pick a name (it stays saved) and create a run, which gets a code like `RUN-4821` and a `?run=RUN-4821` link to send your teammates, or you join one with its code. In the lobby the host picks the sprint (or an unlocked bonus level) and starts it. Everyone has their own colour and their name above their head; bugs chase whoever is closest, and waves and bosses scale with the number of players. Whoever burns out stays down until a teammate stands next to them for a few seconds; you lose when everyone is down. At the end of the run there's the team leaderboard and the host starts the next one. If you drop your connection, you rejoin in your own seat with the same name. Single player is unchanged and doesn't use the server.
- **Music:** an original 80s-style 8-bit loop (two pulse channels, triangle bass, noise drums), synthesized with WebAudio. The menu has a calm track (it starts on the first tap or key press, as browsers require); in game the loop speeds up for the boss and stops while paused; M mutes it along with the sound effects.
- **Mobile:** on touch devices two virtual sticks appear. The left one moves; the right one aims and shoots, with aim assist, and held still it shoots the nearest bug. There are also DASH, ⏪ `git reset --hard` and 🔴 Breakpoint buttons, plus pause and audio at the top. The chat gets compact, and in portrait the game asks you to rotate the phone. On Android (and iPad) starting a sprint switches to fullscreen locked in landscape, with a ⛶ button to exit; on iPhone, which doesn't allow it, the menu suggests "Add to Home Screen" (the manifest opens the game fullscreen).
- **Languages:** English (default) and Italian, from the EN/IT switch in the menu or with `?lang=it`; the choice stays saved. Bug titles are in English in both languages, like in a real backlog.

## Architecture

The simulation is a fixed-step (60 Hz) [Ritmo](https://github.com/typeonce-dev/ritmo) ECS, deterministic and headless; the browser is just a host.

- `src/sim/` — schema (components, resources, events), systems (`player`, `waves`, `movement`, `boss`, which runs every boss's fight by its pattern, `combat`, `missions`, `interruptions`, `epics`), schedule, and the `View` inspector the renderer reads. Randomness only from the seeded `Random`, trigonometry from `Ops`: same seed + same input = same game. `tiers.ts` holds the content tiers: the one table saying which sprint introduces each pickup, read by drops, missions and calls, which Endless climbs a tier every 3 waves. Per-kind tuning tables live here too, next to the systems that read them: `weapons.ts` (`WEAPONS`, `FLAME`), `statuses.ts` (`statusEffects`), `tiers.ts` (`contentTiers`), `constants.ts` (`ticketScales`, `STORY_SUBTASKS`, `EPIC`, `DEPLOY`, and the per-boss `RACE`, `LOOP`, `STACK`). `bosses.ts` holds the boss patterns: `bossRules`, one entry per pattern saying how it fights and what a hit turns it into, plus the key prefixes of the minions bosses drop. `walls.ts` answers every question about walls (is a body in one, push it out, does one stand between two points, the way round it); `hardcore.ts` holds the hardcore rules (`HARDCORE`, and which pickups it leaves out).
- `src/content/` — data (game tuning tables excepted, see `src/sim/`): the made-up backlog, levels, clients, and `arenas.ts` (each floor a level is played on, `ArenaId`, and its walls, the cubicle partitions built by `cubicle`). Closed tables with `satisfies Record<...>`. All text lives in `src/content/text/{en,it}.ts`, typed by `Strings` in `i18n.ts`; the simulation reads the language from the `Language` resource, fixed for the whole level.
- `src/progress.ts` — what this browser has achieved (sprints unlocked, bonus levels and Endless arenas unlocked, best scores, Endless records per arena × hardcore, hardcore badges): pure functions over the JSON the host keeps in local storage.
- `src/host/` — input (keyboard + mouse + touch sticks → intents), renderer, client chat (DOM), WebAudio-synthesized audio (sound effects in `audio.ts`, music in the `music.ts` sequencer).
- `src/net/protocol.ts` — the messages between the browser and the run server (JSON over WebSocket, path `/runs`), with validation of everything that comes from the browser.
- `src/server/` — multiplayer runs: `rooms.ts` (rooms, lobby, names, each run's simulation, no networking), `socket.ts` (WebSocket with `ws` on any Node HTTP server), `main.ts` (production server on Node), `worker.ts` (the Cloudflare deploy: a Worker and one Durable Object holding every run). In development the plugin in `vite.config.ts` attaches runs to the dev server itself: `pnpm dev` is all you need.
- Rendering: `render-pixi.ts` draws with [Pixi](https://pixijs.com/) (WebGL). Every shape is painted once by the Canvas 2D painters in `paint.ts` into a texture, glow included, and each frame only places sprites: it looks the same as the Canvas renderer and keeps 60 fps with hundreds of bugs. `render.ts`, the Canvas 2D renderer drawing with the same painters every frame, is the fallback without WebGL and is forced with `?renderer=canvas`. Both draw only from the `View`, so solo and multiplayer render the same way.
- `bench/` (dev only) — `node bench/fixtures.ts` saves real views from headless play; with `pnpm dev` running, `node bench/shots.ts` screenshots them with both renderers and reports the differing pixels, and `node bench/run.ts` measures frame rates with crowds of 30–300 bugs (`CHROMIUM_PATH` picks the browser).
- The server is authoritative: it runs the same simulation at 60 Hz and sends the view at 30 Hz; browsers only send input (30 times a second) and draw by interpolating between two frames (`src/host/net.ts`).
- `test/simulation.test.ts` — an autopilot plays the levels headless with the same intents as a player, in teams too. `test/rooms.test.ts` — the rooms with fake browsers. `test/progress.test.ts` — unlocks and best scores, from saved JSON and back.
